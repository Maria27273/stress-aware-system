# API-спецификация StressAware

 API построен по принципам REST и использует JSON для обмена данными.

API разделен на **5 логических групп** по ролям пользователей:
- **Сотрудник** — работа с личным кабинетом
- **Руководитель** — просмотр статистики по отделу
- **HR-директор** — управление отчетностью и аналитикой
- **Психолог** — работа с задачами и заметками
- **Администратор** — управление интеграциями


## Общие принципы

### Аутентификация

Все запросы к API требуют авторизации. Токен передается в заголовке `Authorization`:

Токен содержит информацию о роли пользователя, что определяет доступные эндпоинты.

### Формат ответов

Все успешные ответы возвращаются в формате JSON. Коды ответов:

| Код | Значение |
|-----|----------|
| 200 | Успешный запрос |
| 201 | Ресурс создан |
| 400 | Некорректные параметры запроса |
| 401 | Не авторизован |
| 403 | Доступ запрещен (недостаточно прав) |
| 404 | Ресурс не найден |
| 409 | Конфликт (например, дублирующий запрос) |



# Описание эндпоинтов API StressAware

## Сотрудник

### GET /employees/me/stress-score
Возвращает текущий индекс стресса сотрудника, зону риска (зеленый, желтый, красный) и историю изменения индекса за последние 30 дней

### GET /employees/me/recommendations
Возвращает список персонализированных рекомендаций по снижению стресса. 

### POST /employees/me/consultation-request
Отправляет  запрос на консультацию к психологу.


## Руководитель отдела

### GET /manager/department/stats
Возвращает анонимизированную статистику по отделу руководителя. 

## HR-директор

### GET /hr/company/stats
Возвращает агрегированную статистику по всей компании. 

### POST /hr/reports/export
Формирует и выгружает отчет по заданным параметрам. HR-директор выбирает период (месяц, квартал, год), отделы (можно все или выборочно) и формат (Excel или PDF). В ответ приходит ссылка на скачивание готового файла.


## Психолог 

### GET /psychologist/tasks
Возвращает приоритизированный список задач для психолога. 

### GET /psychologist/tasks/{task_id}
Возвращает детальную информацию по конкретной задаче: данные о сотруднике (имя, отдел), историю изменения индекса, факторы стресса, все заметки психолога и текущий статус задачи.


## Администратор 

### GET /admin/integrations
Возвращает список всех подключенных интеграций текущей компании. 

### POST /admin/integrations
Настраивает новую интеграцию. 

### PATCH /admin/integrations/{integration_id}
Изменяет настройки существующей интеграции. 

### DELETE /admin/integrations/{integration_id}
Отключает интеграцию. Удаляет подключение к внешней системе. 

## Технические детали

- **Базовый URL:** `https://api.stressaware.com/v1`
- **Формат данных:** JSON
- **Авторизация:** JWT (Bearer Token)
- **Версионирование:** версия указана в URL (`/v1/...`)

Полная техническая спецификация в формате OpenAPI 3.0 доступна в файле `openapi.yaml`.
