# Сценарии исключений

## Назначение документа

В документе описаны нештатные ситуации, которые могут возникнуть при работе системы StressAware, и предусмотренные реакции системы.

Сценарии сгруппированы по источнику возникновения:

* недоступность внешних систем
* проблемы с входными данными
* ошибки бизнес-логики
* проблемы производительности

---

## Сценарии недоступности внешних систем

###  Jira недоступна

| **Что происходит**         | Система не может получить данные о задачах и активности сотрудников из Jira.                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Использует последние успешно полученные данные, фиксирует ошибку интеграции и уведомляет администратора.                                        |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Индекс рассчитан частично на основе последних доступных данных». |
| **Восстановление**         | После восстановления соединения система получает актуальные данные при следующем плановом сборе и обновляет индекс.                             |

---

###  Корпоративный календарь недоступен

| **Что происходит**         | Система не может получить данные о встречах и загруженности сотрудников из корпоративного календаря.                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Использует последние успешно полученные данные, фиксирует ошибку интеграции и уведомляет администратора.                                          |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Индекс рассчитан частично на основе последних доступных данных». |
| **Восстановление**         | После восстановления соединения система получает актуальные данные при следующем плановом сборе и обновляет индекс.                               |

---

### HRIS недоступна

| **Что происходит**         | Система не может получить актуальную информацию о структуре компании и сотрудниках из HR-системы.                                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Использует последнюю успешно загруженную версию данных и фиксирует ошибку интеграции. Администратор получает уведомление.                    |
| **Что видит пользователь** | Ответственному пользователю отображается сообщение: «Используется последняя доступная версия данных». |
| **Восстановление**         | После восстановления соединения система выполняет синхронизацию при следующем плановом импорте.                                              |

---

### Все внешние источники недоступны

| **Что происходит**         | Система не может получить данные ни из одного внешнего источника.                                                      |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Новый расчет индекса не выполняется. Система фиксирует ошибку и уведомляет администратора.                             |
| **Что видит пользователь** | Отображается сообщение: «Сервис временно работает с ограничениями. Актуальные данные недоступны».                      |
| **Восстановление**         | После восстановления хотя бы одного источника система возобновляет получение данных и расчет индекса в штатном режиме. |

## Сценарии, связанные с данными

### 3.1. Недостаточно данных для расчета индекса

| **Что происходит**         | Для сотрудника недостаточно накопленных данных из необходимых источников для расчета индекса.                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Индекс не рассчитывается. Сотруднику присваивается статус «Недостаточно данных».                                                |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Недостаточно данных для расчета индекса». |
| **Восстановление**         | После накопления необходимого объема данных система автоматически рассчитывает индекс.                                          |

---

### Отсутствует согласие на обработку данных

| **Что происходит**         | Сотрудник не предоставил согласие на обработку данных или отозвал ранее предоставленное согласие.                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система прекращает сбор данных сотрудника и не рассчитывает индекс.                                                                     |
| **Что видит пользователь** | Сотруднику отображается сообщение: «Для расчета индекса и получения рекомендаций необходимо предоставить согласие на обработку данных». |
| **Восстановление**         | После предоставления согласия система начинает сбор новых данных. Данные за период отсутствия согласия не восстанавливаются.            |

---

### Некорректные или противоречивые данные

| **Что происходит**         | Система обнаруживает некорректные данные или существенное расхождение показателей, полученных из разных источников.                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система исключает некорректные значения из расчета, если это возможно, фиксирует проблему и сохраняет информацию о качестве данных.                              |
| **Что видит пользователь** | Психолог видит в карточке сотрудника предупреждение: «Обнаружена проблема с качеством данных. Результат рекомендуется интерпретировать с учетом предупреждения». |
| **Восстановление**         | При следующем обновлении система повторно проверяет данные. После устранения проблемы предупреждение снимается.                                                  |

##  Сценарии бизнес-логики

###  Попытка создать второй активный запрос на консультацию

| **Что происходит**         | У сотрудника уже существует активный запрос на консультацию, и он пытается создать новый. |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| **Действие системы**       | Система не создает новый запрос и возвращает пользователю сообщение об ошибке.            |
| **Что видит пользователь** | «У вас уже есть активный запрос. Дождитесь его обработки».                                |
| **Восстановление**         | После завершения или закрытия текущего запроса сотрудник может создать новый.             |

---

### Недопустимый переход статуса задачи

| **Что происходит**         | Психолог пытается перевести задачу в статус, который не предусмотрен текущим состоянием задачи. Например, перевести задачу из «Новая» сразу в «Решена». |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система блокирует недопустимый переход и сообщает пользователю о причине.                                                                               |
| **Что видит пользователь** | «Невозможно изменить статус задачи. Сначала переведите задачу в статус "В работе"».                                                                     |
| **Восстановление**         | Пользователь выполняет допустимый переход, после чего может продолжить работу с задачей.                                                                |

---

### Индекс рассчитан, но задача психологу не создана

| **Что происходит**         | Индекс сотрудника превышает установленный порог, однако задача психологу не была создана из-за технической ошибки.                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Действие системы**       | После завершения расчета система проверяет наличие задачи для сотрудников, находящихся в красной зоне. Если задача отсутствует, система повторяет операцию её создания и фиксирует ошибку. |
| **Что видит пользователь** | После успешного создания психолог видит новую задачу в своем списке.                                                                                                                       |
| **Восстановление**         | Задача создается автоматически, после чего дальнейшая работа выполняется в штатном режиме.                                                                                                 |

##  Сценарии производительности

### Расчет индекса выполняется дольше ожидаемого

| **Что происходит**         | Плановый расчет индекса занимает значительно больше времени, чем обычно.                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Расчет продолжается в фоновом режиме. Система сохраняет ранее рассчитанные значения до завершения нового расчета и фиксирует превышение ожидаемого времени выполнения. |
| **Что видит пользователь** | Пользователь продолжает видеть последние доступные результаты. Администратор получает уведомление: «Расчет индекса выполняется дольше обычного».                       |
| **Восстановление**         | После завершения расчета система обновляет значения индексов.                                                                                                          |

---

### Пиковая нагрузка на систему

| **Что происходит**         | Значительное количество пользователей одновременно обращается к дашбордам и другим функциям системы.                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Действие системы**       | Система продолжает обрабатывать запросы. При невозможности обработать запрос временно возвращает ошибку недоступности сервиса. |
| **Что видит пользователь** | При невозможности обработки запроса отображается сообщение: «Сервис временно перегружен. Попробуйте повторить действие позже». |
| **Восстановление**         | После снижения нагрузки система возвращается к штатной обработке запросов.                                                     |
