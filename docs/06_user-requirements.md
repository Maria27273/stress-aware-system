# User Requirements

## Сотрудник

**UR-01.** Сотрудник должен иметь возможность просматривать свой текущий индекс стресса.

**UR-02.** Сотрудник должен иметь возможность просматривать свою текущую зону риска.

**UR-03.** Сотрудник должен иметь возможность просматривать динамику индекса стресса за выбранный период.

**UR-04.** Сотрудник должен иметь возможность просматривать персональные рекомендации по снижению стресса.

**UR-05.** Сотрудник должен иметь возможность запросить консультацию психолога.

**UR-06.** Сотрудник должен иметь возможность добавить комментарий к запросу на консультацию.

**UR-07.** Сотрудник должен получать подтверждение после успешной отправки запроса.

---

## Руководитель отдела

**UR-08.** Руководитель должен иметь возможность просматривать агрегированную статистику по своему подразделению.

**UR-09.** Руководитель должен иметь возможность отслеживать динамику уровня стресса команды.

**UR-10.** Руководитель должен иметь возможность получать рекомендации по управлению командой.


---

## 3. HR-директор

**UR-11.** HR-директор должен иметь возможность просматривать агрегированную статистику по компании.

**UR-12.** HR-директор должен иметь возможность анализировать распределение сотрудников по зонам риска.

**UR-13.** HR-директор должен иметь возможность отслеживать динамику уровня стресса по подразделениям.

**UR-14.** HR-директор должен иметь возможность оценивать эффективность мероприятий поддержки.

**UR-15.** HR-директор должен иметь возможность выгружать отчеты для руководства.

---

## Корпоративный психолог

**UR-16.** Психолог должен иметь возможность просматривать список сотрудников, требующих внимания.

**UR-17.** Психолог должен иметь возможность просматривать текущий индекс и историю стресса сотрудника.

**UR-18.** Психолог должен иметь возможность видеть факторы, повлиявшие на уровень риска.

**UR-19.** Психолог должен иметь возможность добавлять заметки по сотруднику.

**UR-20.** Психолог должен иметь возможность изменять статус задачи.

**UR-21.** Психолог должен иметь возможность работать с задачами в порядке приоритета.

---

## Администратор

**UR-22.** Администратор должен иметь возможность подключать и настраивать корпоративные системы.

**UR-23.** Администратор должен иметь возможность управлять пользователями и их ролями.

**UR-24.** Администратор должен иметь возможность просматривать состояние интеграций.

**UR-25.** Администратор должен иметь возможность просматривать ошибки и системные логи.
