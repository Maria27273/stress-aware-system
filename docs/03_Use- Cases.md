## UC-03: Запросить консультацию психолога

| **Поле** | **Значение** |
|----------|--------------|
| **Заголовок** | Запрос консультации психолога |
| **Участники** | Сотрудник (основной), Система, Психолог |
| **Предусловие** | Сотрудник авторизован. Психолог зарегистрирован в системе. |
| **Триггер** | Сотрудник нажимает кнопку «Запросить консультацию». |
| **Результат** | Создана задача для психолога. Сотрудник получил подтверждение. |

**Описание:**
1. Сотрудник нажимает кнопку «Запросить консультацию».
2. Система проверяет, есть ли у сотрудника активные запросы.
3. Система открывает форму с полем для комментария (опционально).
4. Сотрудник вводит комментарий и нажимает «Отправить».
6. Система создает задачу психологу со статусом «Новая».
7. Система присваивает задаче приоритет на основе текущего индекса стресса сотрудника.
8. Система отображает сотруднику сообщение: «Запрос отправлен. Психолог свяжется с вами».

**Расширения:**
- 2.1. У сотрудника уже есть активный запрос  
  2.1.1. Система не создает новую задачу.  
  2.1.2. Система отображает сообщение: «У вас уже есть активный запрос. Дождитесь ответа психолога».

## UC-20: Создать задачу психологу

| **Поле** | **Значение** |
|----------|--------------|
| **Заголовок** | Создать задачу психологу |
| **Участники** | Система (основной), Психолог |
| **Предусловие** | У сотрудника есть индекс стресса > 6.0. |
| **Триггер** | Индекс стресса сотрудника перешел в красную зону (> 6.0). |
| **Результат** | В системе создана задача для психолога. |

**Описание (основной сценарий):**
1. Система фиксирует переход сотрудника в красную зону.
2. Система проверяет, есть ли у сотрудника уже открытая задача.
3. Система создает задачу психологу со статусом «Новая».
4. Система заполняет карточку задачи: имя сотрудника, индекс стресса, факторы стресса.
5. Система добавляет задачу в список психолога с приоритетом на основе индекса.

**Расширения (альтернативные сценарии):**
- 2.1. У сотрудника уже есть активная задача
  2.1.1. Система не создает дубликат.  
  2.1.2. Система обновляет существующую задачу: актуализирует индекс и факторы стресса.
