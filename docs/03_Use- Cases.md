# Use Case

Выделены  **20 вариантов использования**, которые описывают ключевые сценарии взаимодействия с продуктом.


## Краткое описание вариантов использования

| ID | Use Case | Актор | Краткое описание |
|----|----------|-------|------------------|
| UC-01 | Просмотреть свой индекс стресса | Сотрудник | Просмотр текущего индекса (0–10), зоны риска и графика динамики за 30 дней |
| UC-02 | Просмотреть рекомендации | Сотрудник | Получение персонализированных советов по снижению стресса |
| UC-03 | Запросить консультацию психолога | Сотрудник | Отправка анонимного запроса на консультацию к психологу |
| UC-04 | Просмотреть дашборд отдела | Руководитель | Просмотр анонимизированной статистики по своему отделу |
| UC-05 | Просмотреть рекомендации для руководителя | Руководитель | Получение советов по управлению командой на основе данных о стрессе |
| UC-06 | Просмотреть дашборд компании | HR-директор | Просмотр агрегированной статистики по всей компании |
| UC-07 | Выгрузить отчет | HR-директор | Выгрузка отчета в Excel или PDF для руководства |
| UC-08 | Просмотреть эффективность мер поддержки | HR-директор | Оценка того, сколько сотрудников получили помощь и с каким результатом |
| UC-09 | Просмотреть список сотрудников в красной зоне | Психолог | Получение приоритизированного списка сотрудников с высоким риском выгорания |
| UC-10 | Просмотреть историю стресса сотрудника | Психолог | Просмотр динамики индекса за последние 30–90 дней |
| UC-11 | Вести заметки по сотруднику | Психолог | Возможность оставлять заметки по каждому случаю |
| UC-12 | Изменить статус задачи | Психолог | Изменение статуса работы с сотрудником (новая → в работе → решена) |
| UC-13 | Настроить интеграции | Администратор | Подключение Jira, календарей, Active Directory через интерфейс |
| UC-14 | Управлять пользователями и ролями | Администратор | Назначение ролей сотрудникам |
| UC-15 | Просмотреть логи системы | Администратор | Просмотр логов интеграций и ошибок |
| UC-16 | Собирать данные из Jira | Система | Автоматический сбор данных о задачах и активности сотрудников |
| UC-17 | Собирать данные из календаря | Система | Автоматический сбор данных о встречах и загруженности |
| UC-18 | Рассчитывать индекс стресса | Система | Автоматический расчет индекса стресса для всех сотрудников |
| UC-19 | Обновлять зоны риска | Система | Автоматическое обновление зоны риска при изменении индекса |
| UC-20 | Создавать задачи психологу | Система | Автоматическое создание задач при переходе сотрудника в красную зону |
