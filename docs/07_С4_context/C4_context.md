### C4 Context Diagram

На первом уровне C4-модели StressAware представлена как единая система без раскрытия её внутренней архитектуры. Диаграмма показывает окружение системы: пользователей, внешние корпоративные системы и основные направления взаимодействия между ними.

#### Пользователи системы

**Сотрудник**

Использует StressAware для просмотра собственного индекса стресса, зоны риска и динамики показателя. Также сотрудник получает персональные рекомендации и может самостоятельно запросить консультацию корпоративного психолога.

**Руководитель**

Получает доступ к агрегированной статистике своего подразделения: распределению сотрудников по зонам риска, динамике показателей и рекомендациям по управлению командой. 

**HR-директор**

Использует систему для анализа состояния сотрудников на уровне всей компании. 
**Корпоративный психолог**

Использует StressAware для работы с сотрудниками, требующими внимания. Психолог получает список приоритетных задач, может просматривать динамику и факторы стресса сотрудника, изменять статус задачи.

**Системный администратор**

Отвечает за техническую эксплуатацию системы: подключает и настраивает интеграции с корпоративными системами, а также управляет пользователями и их ролями.

#### Внешние системы

**Jira**

Передаёт StressAware информацию о рабочих задачах сотрудников, сроках выполнения, просроченных задачах и активности. Эти данные используются для оценки рабочей нагрузки и дедлайнов.

**Корпоративный календарь**

Предоставляет информацию о рабочих встречах сотрудников, включая количество и продолжительность встреч. Данные используются для оценки нагрузки на календарь.

**HRIS**

Предоставляет данные о сотрудниках и организационной структуре компании: подразделениях, должностях и других необходимых атрибутах.

#### Основные взаимодействия

Основной поток взаимодействия с внешними системами выглядит следующим образом:

**Jira / Корпоративный календарь / HRIS → StressAware**

Внешние системы передают данные, необходимые для расчёта и анализа индекса стресса.

Пользователи взаимодействуют со StressAware через соответствующие интерфейсы:

**Сотрудник → StressAware**
Просмотр собственного состояния, получение рекомендаций и запрос консультации.

**Руководитель → StressAware**
Получение агрегированной информации о состоянии отдела.

**HR-директор → StressAware**
Анализ состояния компании и эффективности мер поддержки.

**Корпоративный психолог → StressAware**
Работа с сотрудниками в зоне риска и задачами психолога.

**Системный администратор → StressAware**
Настройка интеграций и управление доступом пользователей.

### Архитектурная граница

На данном уровне StressAware рассматривается как **единая система («чёрный ящик»)**. Внутренние компоненты, база данных, API и бизнес-логика намеренно не отображаются.

Детализация внутреннего устройства системы представлена на следующем уровне C4-модели — **Container Diagram**.
