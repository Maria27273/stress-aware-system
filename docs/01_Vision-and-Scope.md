# Vision and Scope

**StressAware** — это сервис предиктивной аналитики для HR-департаментов, который помогает компаниям автоматически отслеживать риск эмоционального выгорания сотрудников.

Продукт интегрируется с корпоративными системами клиента (Jira, календари, HRIS) и на основе поведенческих данных рассчитывает для каждого сотрудника индекс стресса. На основе этого индекса система:

- Строит дашборды для HR и руководителей (с соблюдением анонимности)
- Дает сотруднику персональные рекомендации по снижению стресса
- Формирует задачи психологам при высоком риске

Компании подключают StressAware к своим системам через REST API и вебхуки и получают готовую инфраструктуру мониторинга здоровья сотрудников без необходимости разрабатывать её с нуля.

**Главная ценность:** готовый инструмент, который позволяет компаниям перейти от реактивного управления к проактивному, снижая текучку кадров без доработок со стороны внутреннего IT.


##  Бизнес-проблема

### Ситуация в отрасли

По данным совместного исследования hh.ru, Via MD, Работа.ру и СберПодбор (2025 год) **77%** работодателей признают, что выгорание сотрудников напрямую ухудшает атмосферу в коллективе и ведет к росту увольнений. 
**38%** компаний называют рост числа выгоревших сотрудников одной из главных проблем года.
При этом лишь **17%** организаций системно инвестируют в удержание персонала.

### Бизнес-возможность

Цель проекта - снизить текучесть на **15%** за счет внедрения системы, которая позволит:

- Заблаговременно выявлять сотрудников с высоким риском выгорания
- Автоматически предлагать им адресные меры поддержки
- Перевести HR-процессы из режима «реагирования» в режим «предупреждения»


## Границы проекта 

### In Scope

**Сбор и анализ данных:**

- Интеграция с Jira через REST API и вебхуки для получения данных о задачах, дедлайнах, активности сотрудника
- Интеграция с корпоративным календарем (Google/Outlook) через OAuth для получения информации о встречах и загруженности
- Интеграция с HRIS для импорта организационной структуры (отделы, роли, дата найма)

**Расчет и визуализация:**

- Расчет индивидуального индекса стресса (от 0 до 10) на основе данных из Jira и календаря
- Разбивка сотрудников по зонам риска: зеленый, желтый, красный
- Личный кабинет сотрудника с его индексом стресса и персональными рекомендациями
- Дашборд для руководителя с анонимизированной статистикой по его отделу
- Дашборд для HR-директора с агрегированной статистикой по всей компании
- Модуль для психолога с приоритизированным списком сотрудников из красной зоны

**Автоматизация и поддержка:**

- Автоматическое создание задач психологу при переходе сотрудника в красную зону
- Генерация персонализированных рекомендаций для сотрудников на основе их индекса и факторов стресса

### 3.2. Out of Scope

- Автоматические кадровые решения (увольнения, переводы, дисциплинарные меры) — система дает только рекомендации
- Медицинская диагностика или постановка диагнозов
- Отправка уведомлений напрямую
- Интеграция с корпоративными мессенджерами (Telegram, Slack, Teams)
