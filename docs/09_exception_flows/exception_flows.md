# Сценарии исключений

## Назначение документа

В документе описаны нештатные ситуации, которые могут возникнуть при работе системы StressAware, и предусмотренные реакции системы.

Сценарии сгруппированы по источнику возникновения:

* недоступность внешних систем
* проблемы с входными данными
* ошибки бизнес-логики
* проблемы производительности

---

## Сценарии недоступности внешних систем

### Jira недоступна

| **Что происходит**         | Система не может получить данные о задачах и активности сотрудников из Jira.                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система не выполняет новый расчёт с использованием недоступных данных, сохраняет последние успешно полученные данные и фиксирует ошибку интеграции. |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Актуальные данные из Jira временно недоступны».                                                          |
| **Восстановление**         | После восстановления соединения система повторно выполняет синхронизацию и обновляет данные для последующего расчёта индекса.                       |

---

### Корпоративный календарь недоступен

| **Что происходит**         | Система не может получить данные о встречах и рабочей загрузке сотрудников из корпоративного календаря.                                             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система не выполняет новый расчёт с использованием недоступных данных, сохраняет последние успешно полученные данные и фиксирует ошибку интеграции. |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Актуальные данные календаря временно недоступны».                                                        |
| **Восстановление**         | После восстановления соединения система повторно выполняет синхронизацию и обновляет данные для последующего расчёта индекса.                       |

---

### HRIS недоступна

| **Что происходит**         | Система не может получить актуальную информацию о сотрудниках и организационной структуре из HRIS. |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система сохраняет последнюю успешно полученную версию данных и фиксирует ошибку интеграции.        |
| **Что видит пользователь** | В интерфейсе отображается сообщение: «Используется последняя доступная версия данных HRIS».        |
| **Восстановление**         | После восстановления соединения система повторно выполняет синхронизацию и обновляет данные.       |

---

### Все внешние источники недоступны

| **Что происходит**         | Система не может получить данные ни из одного подключённого внешнего источника.                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Новый расчёт индекса не выполняется. Система сохраняет последние корректные значения и фиксирует ошибки интеграций. |
| **Что видит пользователь** | Отображается сообщение: «Сервис временно работает с ограничениями. Актуальные данные недоступны».                   |
| **Восстановление**         | После восстановления доступности внешних систем система возобновляет синхронизацию и расчёт индекса.                |

## Сценарии, связанные с данными

### Недостаточно данных для расчёта индекса

| **Что происходит**         | Для сотрудника недостаточно данных из необходимых источников для расчёта Stress Index.   |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **Действие системы**       | Новый индекс не рассчитывается. Последнее корректное значение сохраняется без изменений. |
| **Что видит пользователь** | В личном кабинете отображается сообщение: «Недостаточно данных для расчёта индекса».     |
| **Восстановление**         | После накопления необходимого объёма данных система выполняет расчёт индекса.            |

---

### Отсутствует согласие на обработку данных

| **Что происходит**         | Сотрудник не предоставил согласие на обработку данных или отозвал ранее предоставленное согласие.                            |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система прекращает сбор новых данных сотрудника и не выполняет расчёт Stress Index.                                          |
| **Что видит пользователь** | Отображается сообщение: «Для расчёта индекса и получения рекомендаций необходимо предоставить согласие на обработку данных». |
| **Восстановление**         | После предоставления согласия система начинает сбор новых данных. Данные за период отсутствия согласия не восстанавливаются. |

---

### Некорректные или противоречивые данные

| **Что происходит**         | Система обнаруживает некорректные данные или существенное расхождение показателей, полученных из разных источников.                                                                |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система исключает некорректные значения из расчёта, если это возможно, и фиксирует информацию о проблеме с данными.                                                                |
| **Что видит пользователь** | При наличии влияния проблемы на результат отображается предупреждение: «Обнаружена проблема с качеством данных. Результат рекомендуется интерпретировать с учётом предупреждения». |
| **Восстановление**         | При следующем обновлении система повторно проверяет данные. После устранения проблемы предупреждение перестаёт отображаться.                                                       |

## Сценарии бизнес-логики

### Попытка создать второй активный запрос на консультацию

| **Что происходит**         | У сотрудника уже существует активный запрос на консультацию, и он пытается создать новый. |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| **Действие системы**       | Система не создаёт новый запрос и сообщает пользователю о наличии активного запроса.      |
| **Что видит пользователь** | «У вас уже есть активный запрос. Дождитесь его обработки».                                |
| **Восстановление**         | После завершения или закрытия текущего запроса сотрудник может создать новый.             |

---

### Недопустимый переход статуса задачи

| **Что происходит**         | Психолог пытается перевести задачу в статус, который не предусмотрен текущим состоянием задачи. Например, перевести задачу из «Новая» сразу в «Решена». |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система блокирует недопустимый переход и сообщает пользователю о допустимой последовательности изменения статуса.                                       |
| **Что видит пользователь** | «Невозможно изменить статус задачи. Сначала переведите задачу в статус "В работе"».                                                                     |
| **Восстановление**         | Пользователь выполняет допустимый переход и продолжает работу с задачей.                                                                                |

---

### Индекс рассчитан, но задача психологу не создана

| **Что происходит**         | Stress Index сотрудника превышает установленный порог, однако задача психологу не была создана.                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Система фиксирует ошибку и выполняет повторную попытку создания задачи. Перед созданием дополнительно проверяется отсутствие активной задачи. |
| **Что видит пользователь** | После успешного создания задачи психолог видит её в своём списке.                                                                             |
| **Восстановление**         | После успешного создания задачи дальнейшая обработка выполняется в штатном режиме.                                                            |

---

## Сценарии производительности

### Расчёт индекса выполняется дольше ожидаемого

| **Что происходит**         | Расчёт Stress Index занимает значительно больше времени, чем обычно.                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Действие системы**       | Расчёт продолжается. Последние корректно рассчитанные значения сохраняются до завершения нового расчёта. |
| **Что видит пользователь** | Пользователь продолжает видеть последние доступные результаты.                                           |
| **Восстановление**         | После завершения расчёта система сохраняет новые значения и обновляет отображаемые показатели.           |

---

### Пиковая нагрузка на систему

| **Что происходит**         | Значительное количество пользователей одновременно обращается к дашбордам и другим функциям системы.                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Действие системы**       | Система продолжает обрабатывать запросы в пределах доступных ресурсов. При невозможности обработать запрос система не изменяет сохранённые данные и возвращает пользователю сообщение об ошибке. |
| **Что видит пользователь** | «Сервис временно перегружен. Попробуйте повторить действие позже».                                                                                                                               |
| **Восстановление**         | После снижения нагрузки система возвращается к штатной обработке запросов.                                                                                                                       |
